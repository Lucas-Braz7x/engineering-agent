# Engineering Agent System (EAS)

> Documento inicial de arquitetura e produto — simples o suficiente para começar, aberto para evolução.

Um sistema genérico de agentes de IA para auxiliar no ciclo de desenvolvimento de software, independente da linguagem, framework ou infraestrutura utilizada pelo projeto.
