# Princípios do projeto

[← Índice](../doc.md)

Colocar no README desde o início:

1. **Language agnostic** — o core não pertence a uma linguagem.
2. **Human controlled** — autonomia configurável e limitada.
3. **Specialized agents** — responsabilidade clara por agente.
4. **Persistent context** — decisões como artefatos, não só conversa.
5. **Simple by default** — evitar complexidade desnecessária.
6. **Tool driven** — interação via ferramentas bem definidas.
7. **Observable** — execução compreensível depois.
8. **Extensible** — novos agentes, skills, adapters e workflows sem reescrever o core.
