## Objetivos principais

O sistema deve:

- funcionar com diferentes linguagens
- detectar automaticamente a stack do projeto
- fornecer contexto estruturado aos agentes
- possuir agentes especializados
- possuir workflows reutilizáveis
- permitir uso via CLI
- integrar-se ao Git
- executar comandos do projeto
- analisar resultados de testes
- produzir artefatos persistentes
- permitir intervenção humana
- funcionar inicialmente com Cursor/Claude e posteriormente possuir seu próprio runtime
