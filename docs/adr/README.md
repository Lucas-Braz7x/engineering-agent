# Architecture Decision Records (ADR)

[← Índice](../../doc.md)

ADRs registram decisões técnicas **duráveis**. O agente Documenter cria entradas aqui quando o workflow ou o escopo pedido justifica.

## Numeração

- Formato: `NNNN-kebab-title.md` (quatro dígitos, ex. `0001-example.md`).
- Use o próximo número livre na pasta.
- Status no corpo do ADR: `Proposed`, `Accepted`, ou `Superseded by NNNM`.
