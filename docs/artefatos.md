O sistema deve preservar o trabalho dos agentes:

```text
.ai/workspace/
├── requirement.md
├── architecture.md
├── challenge.md
├── test-plan.md
├── security-review.md
├── code-review.md
└── debug-report.md
```

Isso permite: auditoria, continuidade, revisão humana, debugging do próprio sistema, comparação entre decisões.
