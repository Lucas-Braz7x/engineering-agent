# Não objetivos

[← Índice](../doc.md)

A primeira versão **não** deve tentar:

- substituir IDE
- substituir GitHub
- criar um novo framework de agentes complexo
- suportar dezenas de linguagens manualmente
- executar código arbitrário sem controle
- implementar uma infraestrutura distribuída
- criar uma UI web
- tornar os agentes completamente autônomos

**Foco inicial:** criar um sistema pequeno, previsível e extensível para coordenar agentes de engenharia.
