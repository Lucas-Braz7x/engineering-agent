# Primeiro MVP

[← Índice](../doc.md)

**Restrição forte:** o MVP deve pegar um repositório desconhecido, entendê-lo e produzir uma **análise arquitetural útil**.

```text
engineering-agent init → Detect project
        ↓
engineering-agent analyze → Architect → architecture.md
        ↓
engineering-agent review → Reviewer → code-review.md
```

Se isso funcionar bem, já há uma primeira versão demonstrável.
