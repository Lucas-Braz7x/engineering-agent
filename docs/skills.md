# Skills

[← Índice](../doc.md)

**Skills** representam conhecimento específico.

```text
skills/
├── languages/
│   ├── python.md
│   ├── typescript.md
│   └── go.md
├── frameworks/
│   ├── fastapi.md
│   ├── nestjs.md
│   └── gin.md
└── infrastructure/
    ├── aws.md
    ├── docker.md
    └── postgres.md
```

Um Agent pode utilizar várias Skills.

**Exemplo:** Reviewer + TypeScript + NestJS + PostgreSQL + Project Rules
