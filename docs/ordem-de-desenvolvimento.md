# Ordem de desenvolvimento recomendada

[← Índice](../doc.md)

```text
                    AGORA
                      ↓
              Markdown Agents
                      ↓
             Testar os workflows
                      ↓
              Python CLI / Core
                      ↓
               Project Detection
                      ↓
                    Tools
                      ↓
             Autonomous Workflows
                      ↓
             GitHub / AWS / CI
```

**Não começar pelo “framework de agentes”.** Primeiro tornar agentes e workflows bons **manualmente** (Cursor + `.ai/`). Depois codificar exatamente o que funcionou — reduz o risco de semanas em infraestrutura para um fluxo ainda não validado.
