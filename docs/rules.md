# Rules

[← Índice](../doc.md)

**Rules** são restrições e princípios que devem ser respeitados.

**Exemplo:** `.ai/rules/architecture.md`

```markdown
# Architecture Rules

1. Business logic must not depend on infrastructure.
2. External services must be isolated behind interfaces.
3. Avoid unnecessary abstractions.
4. New dependencies require justification.
5. Prefer simple solutions when requirements allow them.
```

Outras rules típicas: `coding.md`, `security.md`, `git.md`, `testing.md`
