# Princípio fundamental

[← Índice](../doc.md)

O sistema deve separar quatro conceitos com responsabilidades distintas:

| Conceito    | Papel resumido                          |
|------------|------------------------------------------|
| **Agents**    | Responsabilidades de engenharia          |
| **Skills**    | Conhecimento específico (stack, cloud…)  |
| **Rules**     | Restrições e princípios obrigatórios     |
| **Workflows** | Orquestração dos agentes                 |
